# Foundry Fundamentals Section 3: HTML/JS Fund Me

## Topik
- Quick Fullstack / Front End Tutorial
- Cara connect frontend ke smart contract
- MetaMask integration
- Function selectors

## Yang Dipelajari
- Cara bikin HTML/JS frontend untuk interact dengan smart contract
- Cara MetaMask work dengan browser
- Introduction to function selectors
- Deploy FundMe contract lalu interact dari frontend

## Setup
1. Deploy FundMe contract ke local network (Anvil) atau testnet
2. Buka `index.html` di browser
3. Connect MetaMask ke jaringan yang sama
4. Fund dan withdraw melalui frontend

## Files
- `index.html` — Frontend HTML + JavaScript
- `app.js` — Logic untuk interact dengan contract
